Mail Sender — Политика конфиденциальности

Дата последнего обновления: 7 октября 2026 г.

Что делает приложение

Mail Sender — личное приложение, которое используется только его владельцем для отправки собственных писем и уведомлений со своего аккаунта Gmail с помощью Gmail API. Приложение запрашивает единственное разрешение: gmail.send (отправка писем).

Какие данные используются

Приложение не читает, не удаляет и не изменяет письма в почтовом ящике. Оно не собирает данные других пользователей, не использует cookies и не ведёт аналитику.

Хранение и передача данных

Токен доступа хранится только на сервере владельца приложения. Данные не передаются, не продаются и не раскрываются третьим лицам. Использование информации, полученной через Google API, соответствует Google API Services User Data Policy, включая требования Limited Use.

Отзыв доступа

Доступ можно в любой момент отозвать на странице myaccount.google.com/permissions.

Mail Sender — Privacy Policy

Last updated: October 7, 2026

What the app does

Mail Sender is a private application used solely by its owner to send their own emails and notifications from their own Gmail account via the Gmail API. The app requests a single permission: gmail.send (send email).

Data we use

The app does not read, delete or modify messages in the mailbox. It does not collect data from other users, does not use cookies and does not run analytics.

Storage and sharing

The access token is stored only on the app owner's server. No data is sold, shared or disclosed to third parties. The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
